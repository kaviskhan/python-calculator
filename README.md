Python Calculator 🧮

A beginner-friendly calculator built using Python.

📌 Project Description

This project is a simple command-line calculator that performs basic mathematical operations.

The calculator can perform:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Exit option

It also handles invalid inputs and prevents division by zero.

🛠️ Technologies Used

- Python

🧠 Python Concepts Practiced

- "print()"
- "input()"
- Variables
- "if / elif / else"
- "while" loop
- "break"
- "continue"
- "try / except"
- "float()"
- Arithmetic operators

▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

python calculator.py
